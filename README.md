# Deep Cinema

Личный онлайн-кинотеатр для **Windows** и **Android TV** в стиле «Стекло» (liquid glass).

## Как получить приложение

Каждое изменение в ветке `main` автоматически собирается в облаке GitHub:

1. Вкладка **Releases** → последняя версия.
2. **Windows:** скачать `DeepCinema-…-windows.zip`, распаковать, запустить `Deep Cinema.exe`.
3. **Android TV:** установить `DeepCinema-….apk`.

Все версии подписаны одним ключом, поэтому новые ставятся поверх старых, без удаления.

## Что внутри

| Папка | Что там |
|---|---|
| `lib/core` | тема «Стекло», настройки |
| `lib/data` | модели, клиент TMDB, «Моё» (избранное, история, оценки) |
| `lib/widgets` | стеклянные панели, фокус для пульта, постеры |
| `lib/screens` | главная, каталог и фильтры, «Моё», карточка, плеер, профиль |
| `tool/` | донастройка под Android TV и Windows, иконки, ключ подписи |
| `.github/workflows` | облачная сборка |

Папки `android/` и `windows/` не хранятся в репозитории — они создаются при сборке командой `flutter create` и донастраиваются скриптом `tool/patch_platforms.py`.
