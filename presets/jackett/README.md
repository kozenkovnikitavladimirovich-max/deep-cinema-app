# Свои трекеры «в комплекте»

Файлы из папки `Indexers` попадают в установщик и при первом запуске
копируются во встроенный агрегатор (Jackett). Уже настроенные на компьютере
трекеры не перезаписываются.

Как получить файлы:
1. Настройте трекеры один раз: Deep Cinema → Настройки → Поиск раздач → Трекеры.
2. Откройте папку данных (Настройки → Данные → Папка данных) → `jackett\Indexers`.
3. Загрузите оттуда нужные `.json` в эту папку репозитория (на GitHub: Add file → Upload files).

В файлах могут быть логины и пароли от трекеров — репозиторий должен оставаться закрытым.
