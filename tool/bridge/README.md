# Мост Deep Cinema на Cloudflare (бесплатно, без карты)

Мост — маленькая программа на серверах Cloudflare. Он даёт:

- описания и постеры TMDB, кадры серий и рейтинги без VPN (мост ходит за ними сам);
- вход через Яндекс без доступа к Яндекс Диску (и через Google без Google Диска):
  мост проверяет вход и хранит ваши списки и историю в своей бесплатной базе;
- вход по любой почте и паролю (пароль хранится только в виде необратимого отпечатка);
- вход Яндексом по QR-коду на телевизоре — без ввода кода.

Бесплатно: до 100 000 запросов в сутки, база — 1 ГБ. Карта не нужна.

## Настройка (один раз, ~10 минут)

1. Зарегистрируйтесь на <https://dash.cloudflare.com/sign-up> (нужна только почта).
2. Слева: **Compute (Workers)** → **Workers & Pages** → **Create** → **Create Worker**.
   Имя, например, `deep-cinema` → **Deploy**.
3. **Edit code** → удалите всё в редакторе, вставьте содержимое файла `worker.js`
   из этой папки → **Deploy**.
4. Хранилище: слева **Storage & Databases** → **KV** → **Create** → имя `deep-cinema-data`.
5. Вернитесь в Worker → **Settings** → **Bindings** → **Add** → **KV namespace**:
   имя переменной `DATA`, хранилище `deep-cinema-data` → **Deploy**.
6. Там же **Settings** → **Variables and Secrets** → **Add** → тип **Secret**,
   имя `SESSION_SECRET`, значение — любая длинная случайная строка
   (например, 40 любых букв и цифр) → **Deploy**.
7. Адрес моста — вверху страницы Worker'а, вида `https://deep-cinema.ВАШЕ-ИМЯ.workers.dev`.
   Откройте его в браузере: должно показаться `{"app":"deep-cinema-bridge","kv":true,"secret":true}`.
8. В Deep Cinema: **Настройки → Данные о фильмах → Мост (Cloudflare)** → вставьте адрес.
   (Или пришлите адрес разработчику — он встроит его, и друзьям ничего вводить не придётся.)

## Если Cloudflare замедлен (Россия): мост на Vercel

Тот же мост на Vercel (бесплатно, без карты, вход через GitHub). Код — в папке `vercel/`
(собирается из `worker.js` скриптом `make_vercel.py`).

1. <https://vercel.com/signup> → Continue with GitHub.
2. **Add New → Project** → выберите репозиторий `deep-cinema` → **Root Directory**: `tool/bridge/vercel`
   → Framework: **Other** → **Deploy**.
3. В проекте: **Storage → Create Database → Upstash (Redis)** → бесплатный план → **Connect** к проекту.
4. **Settings → Environment Variables** → `SESSION_SECRET` (любая длинная строка) → Save →
   **Deployments → ⋯ → Redeploy**.
5. Откройте адрес проекта (`https://….vercel.app`) без VPN: должно быть `"kv":true,"secret":true`.

## Мост на Deno Deploy (если регистрация там открыта)

С лета 2025 года в России замедляют Cloudflare: маленькие ответы проходят, картинки и
списки застревают. Тот же мост можно поставить на Deno Deploy (бесплатно, вход через GitHub):

1. Откройте <https://dash.deno.com> → войдите через GitHub.
2. **New Playground** (или New Project → Playground).
3. Удалите код в редакторе, вставьте содержимое файла `deno.js` из этой папки → **Save & Deploy**.
4. **Settings → Environment Variables** → добавьте `SESSION_SECRET` (любая длинная строка) → Save.
5. Хранилище (KV) на Deno подключается само. Если на проверке `kv:false` — в настройках
   проекта включите **KV** (Databases → Create/Attach).
6. Откройте адрес проекта (`https://….deno.dev`) **без VPN**: должно показаться
   `{"app":"deep-cinema-bridge","kv":true,"secret":true}`.
7. Пришлите адрес разработчику или впишите в программе: **Настройки → Сеть → Мост**
   (можно несколько через пробел — программа сама выберет работающий).

## Обновить код моста

Когда код в `worker.js` меняется: страница Worker'а → **Edit code** → выделить всё (Ctrl+A) →
вставить новый код → **Deploy**. Хранилище, секрет и данные пользователей сохраняются.

## Вход через Яндекс без Диска

В настройках вашего приложения на <https://oauth.yandex.ru> в разделе доступов должны быть
отмечены **«Доступ к логину, имени и фамилии, полу»** и **«Доступ к адресу электронной почты»**.
Доступ к Диску больше не нужен (можно оставить — он просто не используется).

Для входа по QR-коду в разделе **Платформы → Веб-сервисы** добавьте второй Redirect URI
(кнопка «+»): адрес моста с `/ya` на конце, например
`https://deep-cinema.ВАШЕ-ИМЯ.workers.dev/ya`.

## Вход по почте: забытый пароль

Cloudflare → **Storage & databases → Workers KV → deep-cinema-data → KV Pairs** →
найдите ключ `acct:почта@пример.ру` → удалите. После этого человек регистрируется заново
с той же почтой и новым паролем — его списки и история сохранятся.

После включения моста при первой синхронизации данные с Диска один раз переносятся в мост.

## Если не работает

- Адрес моста не открывается без VPN — у некоторых провайдеров сервисы Cloudflare замедлены.
  Тогда мост работает с VPN или не работает вовсе; программа в этом случае просто
  продолжает работать как раньше.
- `kv:false` или `secret:false` на проверке — не сделан шаг 5 или 6.
