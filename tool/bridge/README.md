# Мост Deep Cinema на Cloudflare (бесплатно, без карты)

Мост — маленькая программа на серверах Cloudflare. Он даёт:

- описания и постеры TMDB, кадры серий и рейтинги без VPN (мост ходит за ними сам);
- вход через Яндекс без доступа к Яндекс Диску (и через Google без Google Диска):
  мост проверяет вход и хранит ваши списки и историю в своей бесплатной базе;
- вход по любой почте и паролю (пароль хранится только в виде необратимого отпечатка);
- вход Яндексом по QR-коду на телевизоре — без ввода кода.

Бесплатно: до 100 000 запросов в сутки, база — 1 ГБ. Карта не нужна.

## Настройка (один раз, ~10 минут)

1. Зарегистрируйтесь на <https://dash.cloudflare.com/sign-up> (нужна только почта).
2. Слева: **Compute (Workers)** → **Workers & Pages** → **Create** → **Create Worker**.
   Имя, например, `deep-cinema` → **Deploy**.
3. **Edit code** → удалите всё в редакторе, вставьте содержимое файла `worker.js`
   из этой папки → **Deploy**.
4. Хранилище: слева **Storage & Databases** → **KV** → **Create** → имя `deep-cinema-data`.
5. Вернитесь в Worker → **Settings** → **Bindings** → **Add** → **KV namespace**:
   имя переменной `DATA`, хранилище `deep-cinema-data` → **Deploy**.
6. Там же **Settings** → **Variables and Secrets** → **Add** → тип **Secret**,
   имя `SESSION_SECRET`, значение — любая длинная случайная строка
   (например, 40 любых букв и цифр) → **Deploy**.
7. Адрес моста — вверху страницы Worker'а, вида `https://deep-cinema.ВАШЕ-ИМЯ.workers.dev`.
   Откройте его в браузере: должно показаться `{"app":"deep-cinema-bridge","kv":true,"secret":true}`.
8. В Deep Cinema: **Настройки → Данные о фильмах → Мост (Cloudflare)** → вставьте адрес.
   (Или пришлите адрес разработчику — он встроит его, и друзьям ничего вводить не придётся.)
